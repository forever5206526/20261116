// ItemID,Flag
//
// 「Flag」欄位說明（位元遮罩）：
// 1    - 一般地圖中受限制
// 2    - PVP 地圖中受限制
// 4    - GVG 地圖中受限制

// 限制區域：透過 'restricted <number>' 地圖旗標設定

// 256  - 限制區域 4
// 512  - 限制區域 5
// 1024 - 限制區域 6
// 2048 - 限制區域 7
// 4096 - 限制於區域 8
//
// Flag 設為負值時，會取消對應限制。
//
// 範例：
// 1201,1   // 一般地圖禁止裝備小刀
// 608,4    // 在 GvG 與攻城戰城堡中禁止使用世界樹種子

// 519,322  // 玩家對戰地圖（PVP） 地圖及標記為「限制區域 2」或「限制區域 4」的地圖禁止使用牛奶（256+64+2）
