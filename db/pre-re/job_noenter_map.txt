// 定義受到地圖旗標／區域限制而無法進入地圖的職業。
//
// 資料庫格式：
// JobID,FlagZone,GroupLevelBypass
//
// JobID：請參閱 JOB_* 常數或直接使用職業編號。
//
// 「Flag」欄位說明（位元遮罩）：
// 1    - 一般地圖中受限制
// 2    - PVP 地圖中受限制
// 4    - GVG 地圖中受限制
// 8    - 戰場地圖中受限制
// 16   - WOE:TE 城堡中受限制
// 限制區域：透過 'restricted <number>' 地圖旗標設定
// 32   - 限制區域 1
// 64   - 限制區域 2
// 128  - 限制區域 3
// 256  - 限制區域 4
// 512  - 限制區域 5
// 1024 - 限制區域 6
// 2048 - 限制區域 7
// 4096 - 限制區域 8
//
// GroupLevelBypass：可忽略此限制的群組等級（groups.conf）。
//
// 注意事項：
// - 若同一 Job ID 有多筆設定，後面的限制設定會覆寫前面的設定。
// - 此旗標由 'jobcanentermap' 腳本使用。
