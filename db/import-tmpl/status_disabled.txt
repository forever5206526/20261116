// 狀態變更限制資料庫
//
// 定義狀態變更（SC）的限制。
// 停用的 SC 會在此地圖中被移除，或無法成功施加。
//
// 資料庫格式：
// SCType,Flag
//
// 「Flag」欄位說明（位元遮罩）：
// 1    - 一般地圖中受限制
// 2    - PVP 地圖中受限制
// 4    - GVG 地圖中受限制
// 8    - 戰場地圖中受限制
// 限制區域：透過 'restricted <number>' 地圖旗標設定
// 32   - 限制區域 1
// 64   - 限制區域 2
// 128  - 限制區域 3
// 256  - 限制區域 4
// 512  - 限制區域 5
// 1024 - 限制區域 6
// 2048 - 限制區域 7
//
// 範例：
// SC_ENDURE,4   // 玩家進入 GvG 與攻城戰城堡地圖時，霸體狀態會被移除，且無法再次施加。
