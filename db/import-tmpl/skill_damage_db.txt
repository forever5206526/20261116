// 技能傷害調整資料庫
//
// 資料庫格式：
// SkillName,Caster,Map,對玩家傷害{,對魔物傷害{,對首領傷害{,對其他目標傷害}}}
//
// Caster：套用調整效果的對象群組（位元遮罩）。
//		BL_PC = 玩家
//		BL_MOB = 魔物
//		BL_PET = 寵物
//		BL_HOM = 生命體
//		BL_MER = 傭兵
//		BL_ELEM = 元素召喚獸
//
// Map：
// 		1    - 一般地圖（未歸類為下列類型的地圖）
// 		2    - PVP
// 		4    - GVG
// 		8    - 戰場
// 		16   - 'skill_damage' 地圖旗標
// 限制區域：透過 'restricted <number>' 地圖旗標設定
// 		32   - 區域 1
// 		64   - 區域 2
// 		128  - 區域 3
// 		256  - 區域 4
// 		512  - 區域 5
// 		1024 - 區域 6
// 		2048 - 區域 7
//
// 注意事項：
//  	傷害以百分比表示，範圍為 -100 至 100000。
//  	負值會降低傷害，正值會提高傷害（0 = 不變）。
//
// 範例：
// MC_MAMMONITE,BL_PC,1,50 // 一般地圖中，玩家使用金錢攻擊對其他玩家造成 +50% 傷害。
// MO_EXTREMITYFIST,BL_PC,6,-50 // PVP 與 GVG 地圖中，玩家使用阿修羅霸凰拳對其他玩家造成 -50%（減半）傷害。
// AB_ADORAMUS,BL_PC,6,50,0,10,15 // PVP 與 GVG 地圖中，玩家使用讚歌對其他玩家造成 +50% 傷害、對魔物 +0%、對首領 +10%、對其他目標 +15% 傷害。
