// 自訂魔物技能資料庫
//
// 資料庫格式：
// MobID,Dummy value (info only),State,SkillID,SkillLv,Rate,CastTime,Delay,Cancelable,Target,Condition type,Condition value,val1,val2,val3,val4,val5,Emotion,Chat
//
// RATE：符合條件時施放技能的機率（10000 = 100%）。
// DELAY：再次嘗試施放相同技能前的等待時間（毫秒）。
//
// 狀態：
//	any（除死亡外的任何狀態）／idle（待機）／walk（移動）／dead（死亡時）／
//	loot（撿取）／attack（攻擊）／angry（類似攻擊，但玩家尚未攻擊魔物）／
//	chase（受到攻擊後追擊目標）／follow（跟隨目標，
//	未受到攻擊）／anytarget（attack+angry+chase+follow）
//
// 目標：
//	target（目前目標）／self（自身）／friend（友方）／master（主人）／randomtarget（技能範圍內的任意敵人）
//
//	以下項目適用於地面技能，系統會從指定範圍中隨機選擇目標格：
//	    around1（自身周圍 3x3 範圍）／around2（自身周圍 5x5 範圍）／
//	    around3（自身周圍 7x7 範圍）／around4（自身周圍 9x9 範圍）／
//	    around5（目標周圍 3x3 範圍）／around6（目標周圍 5x5 範圍）／
//	    around7（目標周圍 7x7 範圍）／around8（目標周圍 9x9 範圍）／
//	    around = around4
//
// 條件：
//	always（永遠成立）			無條件觸發（不需要條件值）。
//	onspawn			魔物生成／重生時觸發（不需要條件值）。
//	myhpltmaxrate		魔物 HP 降至指定百分比時觸發。
//	myhpinrate		魔物 HP 落在指定百分比範圍時觸發（condition value = 下限，val1 = 上限）。
//	mystatuson		魔物具有指定異常狀態時觸發。
//	mystatusoff		魔物的指定異常狀態結束時觸發。
//	friendhpltmaxrate	魔物友方的 HP 降至指定百分比時觸發。
//	friendhpinrate		魔物友方的 HP 落在指定百分比範圍時觸發（condition value = 下限，val1 = 上限）。
//	friendstatuson		友方具有指定異常狀態時觸發。
//	friendstatusoff		友方的指定異常狀態結束時觸發。
//	attackpcgt		攻擊魔物的玩家數量大於指定數值時觸發。
//	attackpcge		攻擊魔物的玩家數量大於或等於指定數值時觸發。
//	slavelt			從屬魔物數量低於原先指定數量時觸發。
//	slavele			從屬魔物數量小於或等於原先指定數量時觸發。
//	closedattacked		受到近距離近戰攻擊時觸發（不需要條件值）。
//	longrangeattacked	受到遠距離攻擊時觸發，例如弓、槍及遠距離技能（不需要條件值）。
//	skillused		指定技能對魔物施放時觸發。
//	afterskill		After mob casts the specified skill.
//	casttargeted		When a target is in cast range (no condition value).
//	rudeattacked		When mob is rude attacked (no condition value).
//	mobnearbygt		When monsters in range become greater than specified number.
//	groundattacked		When mob is hit by ground targeted skill (no condition value).
//	damagedgt		When single attack deals greater damage than specified number.
//
//	Status abnormalities specified through the statuson/statusoff system:
//	    anybad (any type of state change) / stone / freeze / stun / sleep /
//	    poison / curse / silence / confusion / blind / hiding / sight (unhidden)
//
// Note: if a negative MobID is provided, the skill will be treated as 'global':
//	-1: added for all boss types.
//	-2: added for all normal types.
//	-3: added for all mobs.
